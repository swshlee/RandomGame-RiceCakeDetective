# 떡먹은 사람 찾기

캐릭터 중 한 명이 몰래 떡을 먹고, 캐릭터들이 야바위처럼 자리를 섞은 뒤 누가 떡을 먹었는지 공개하는 랜덤 게임입니다.

## 실행

GitHub Pages:

```text
https://swshlee.github.io/RandomGame-RiceCakeDetective/
```

로컬에서는 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 게임 흐름

- 난이도를 Easy, Normal, Hard 중 선택합니다. Easy는 3명, Normal은 5명, Hard는 7명입니다.
- 캐릭터들이 일렬로 서고, 한 명이 스스로 떡을 먹는 애니메이션이 재생됩니다.
- 카드 프레임 없이 캐릭터 스프라이트가 5번 점프와 슬라이딩으로 자리를 섞습니다.
- 섞기 중에는 긴장감 있는 발랄한 효과음이 재생되고, 결과 공개 시 빵빠레가 재생됩니다.
- `결과 확인` 버튼을 누르면 떡 먹은 캐릭터가 공개됩니다.
